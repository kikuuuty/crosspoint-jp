# ルビ表示の検証

## 仕様

- 原文の親文字と `<rt>` の対応を保持する。文字数による読みの均等分割はしない。
- 親文字1文字ならモノルビ、複数文字ならグループルビとして表示する。
- `<rb>`、交互の親文字/`<rt>`、`<rbc>`/最初の `<rtc>`、`rbspan` に対応する。
  二段目の `<rtc>` や内側の入れ子ルビの読みは表示しない（親文字は保持する）。
- 縦横とも中付き。行頭・行末では本文の実際の先頭/末尾を越えないことを優先し、
  内側へ寄せる。縦書きは最後の文字の後の字間を表示範囲に含めない。
- 隣接するルビは親文字間の中点で表示可能範囲を分け、衝突を防ぐ。
- ルビには本文の追加字間を適用しない。それでも表示可能範囲より長い読みは、
  全文字を保持して字形を等比縮小する。描画用の一時ビットマップは確保しない。
- 原則としてグループ内では折り返さない。親文字自体が一行/一列より長い場合のみ、
  本文を折り返し、読み全体を最初の断片に一度だけ表示する。読みを推測で分割しない。
- メモリ保護のため、未確定ルビを含む解析中の本文は480語未満、1つの読みは4096バイトまで。
  超過時はログを残して章の解析を失敗させる。黙って読みを切り捨てない。
- 切替設定は増やさない。既存のルビ表示ON/OFFを維持し、対応単位は原文に従う。
- セクションキャッシュはVersion 43へ自動再生成する。進捗・書籍情報の形式は変更しない。

## ホストテスト

```sh
bash test/run_ruby_test.sh
```

対応単位、XMLテキストのチャンク境界、長い文字列のムーブ、ルビなしの配列未確保、
配置範囲の総当たり、1bit/2bit字形の縮小と非突出を確認する。さらに実際の `ParsedText.cpp` / `TextBlock.cpp` を、
固定フォント計測値とメモリ上のファイルを使って実行し、縦横のグループ折り返し、
中間flush、禁則との組合せ、ランダムなグループ配置、本文の実表示範囲、
キャッシュの往復・不正な読み長の拒否を確認する。
このテストは実際のフォント字形やパネルへの描画を検証するものではない。

## シミュレータ・実機

```sh
python scripts/generate_ruby_test_epubs.py
```

`test/epubs/ja_ruby_horizontal.epub` と `ja_ruby_vertical.epub` を生成する。
実機のSD、またはシミュレータのSDへコピーし、次を確認する。

1. 原文の書式を有効にし、それぞれ横書き/縦書きで開く。
2. 「漢→かん」「字→じ」が維持され、「今日→きょう」は一括で中央に付く。
3. 行頭・行末・一文字だけの行でルビが本文の外側へ出ない。
4. 連続する長いルビ同士が重ならず、小書き仮名の縦組みが保たれる。
5. 折り返し・400文字付近・ページ境界でルビが欠落/重複しない。
6. 章を開き直してキャッシュを読み込んでも表示が同じ。
7. フォントサイズ・字間・行間・画面の4方向、アンチエイリアスON/OFF、
   ルビON/OFF、ダークモードを変えて回帰を確認する。

ヒープの効果は実機で計測する。ルビなし/多数/長い読みの各ケースで、解析中の最小空き
ヒープ、ページ読込後の空きヒープ、描画中の最大連続空き領域を比較し、ページ送りの
反復で減り続けないことも確認する。削減量は `sizeof(std::string)`、注釈数、文字列長、
フォントキャッシュに依存するため、固定のKB値を前提にしない。
